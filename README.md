# Doable

*Make anything doable.* Instaladores e atualizações do Doable para Windows.

Baixe o instalador mais recente em [Releases](https://github.com/Brunovncs/doable-releases/releases/latest). Depois de instalado, o Doable se atualiza sozinho: as atualizações vêm daqui e são assinadas, e o app só instala o que a Doable publicou.

O código-fonte é privado por enquanto. Este repositório só tem os instaladores.

O instalador ainda não tem assinatura de código da Microsoft, então o Windows pode mostrar o aviso do SmartScreen na primeira vez. Clique em "Mais informações" e depois em "Executar assim mesmo".
